# Small Pots

A student-focused financial wellbeing website with four interactive tools:

- **Savings Growth:** Project savings and compound growth.
- **Budget & Tax:** Estimate take-home income and monthly spending.
- **Retirement:** Estimate pension savings and retirement income.
- **Student Loans:** Compare repayments, overpayments, and investing.

## How to Run

1. Clone or download the repository.
2. Open `final.html` in your web browser.

Alternatively, run a local server from the project directory:

```bash
python3 -m http.server 8000
```

Visit [http://localhost:8000/final.html](http://localhost:8000/final.html).

## Technologies

HTML, CSS, JavaScript, and SVG.

**Note:** Financial calculations are educational estimates, not financial advice.
